# Ejemplos JSON del capítulo 7

Cuatro borradores para cargar individualmente con «Cargar borrador» en la herramienta EPIG de Portugalete.

Fuente: 6__Capitulo_7_Dossieres_MODELO_positivo_v3.docx. Son modelos didácticos, no informes de los expedientes reales. El resultado positivo procede del dossier modelo.

Los ejemplos de subvenciones son bases reguladoras, no convocatorias anuales. Los importes presupuestarios no disponibles quedan vacíos; su explicación se conserva en Objetivos del proyecto.

En Euskera, las dimensiones Participación y Normas sociales se conservan como no pertinentes. El formulario solo admite Sí/No: esas cuatro casillas quedan sin marcar para no transformar «no pertinente» en «no». El JSON se carga, pero la herramienta exige resolver esas casillas antes de exportar un informe final.

Los campos adicionales _fuente conservan el texto completo, las tablas y las notas del dossier. La herramienta no muestra estos campos y los omite al volver a guardar el borrador; conserve los JSON originales.



## 01_OPE_2025_MODELO.json

Nota del dossier modelo
Relación del dossier modelo con el expediente real. No forma parte del informe generado por la herramienta.Este dossier reelabora, como modelo bien integrado, el expediente 4 (resultado positivo). Respecto del expediente real, la versión modelo incorpora al articulado las mejoras que allí quedaron como propuesta —el cómputo de cuidados en el baremo (art. 21.1.c), la protección de la maternidad (art. 21.1.d), las campañas de sensibilización concretadas y el seguimiento con perspectiva de género—, cerrando el cumplimiento del artículo 21.
